Raylib Web Micro-Game with Web Request

Estimated Time: 3–6 hours

Submission: GitHub

Task Brief

Create a polished micro-game in Raylib that runs in the web browser (compiled with Emscripten).

Your game should:

  • Have clear start, play, and end states (not just a demo).
  • Use simple but polished visuals and controls (movement, feedback, basic UI text).
  • Make a web request to an API or local resource.
  • Integrate the fetched data as a core feature of gameplay. For example a Weather API that changes the background (sunny, cloudy, rainy) or affects the mechanics.

You may choose to work in groups of up to 2 individuals.

Deliverables

  • main.cpp with working code

  • A .gif showing the game running in the browser

  • A compiled WebAssembly/HTML build (index.html + .wasm + .js) in a /web folder and on itch.io

  • A README.md including:

    • How to compile with Emscripten (emcc)
    • How to serve and play in a browser (e.g., python3 -m http.server 8000)
    • The source/API you used for the web request
